# EmpresaPro Suite - Railway Deployment

Este paquete contiene todo lo necesario para desplegar **EmpresaPro Suite** (con buscador de inventario, promedio ponderado, multiempresa y estados financieros) en **Railway** mediante GitHub.

## Instrucciones de Despliegue:
1. Sube todos los archivos de esta carpeta directamente a la **raíz** de tu repositorio en GitHub.
2. En Railway, crea un nuevo proyecto seleccionando **Deploy from GitHub repo** y elige tu repositorio.
3. Railway compilará automáticamente la aplicación usando Node.js / Express.
4. Ve a **Settings -> Domains** en Railway para generar tu enlace público.
